# 架构图重绘提示词

## 提示词一：双链路事实架构图

请生成一张 16:9、深色赛博朋克风格但以工程事实为优先的中文技术架构图，标题为“Antigravity 提示词注入与请求路由链路”。使用清晰的矢量节点、正交箭头、简体中文字体，禁止乱码、重叠文字、虚构数字和未经证实的百分比。

必须准确表达以下链路：

1. `Antigravity.exe` 启动 VS Code 扩展 `plugins/zk-proxy-pro/extension.js`。
2. 扩展启动本地 `127.0.0.1` HTTP 代理；默认端口按用户名 FNV-1a 映射到 `8889~8988`，允许显式配置，端口冲突时可回退空闲端口。
3. Antigravity 主链路是 `language_server / LS-CDP → HTTP Proxy`，不是 ACP stdio 主链路。
4. 请求分类包含：`GEMINI_REST_CHAT`、`CHAT_PROTO`、`CHAT_RAW`、`INFER_STRIP`、`MODEL_UNLOCK`、`PASSTHROUGH`。
5. `SP_MODE=invert` 时：
   - Connect-RPC 的 `GetChatMessage`、`GetChatMessageV2`、`RawGetChatMessage` 进入提示词替换；
   - Gemini REST 公开路径替换 `systemInstruction` / `system_instruction` 或 `contents[].parts[].text`；
   - Gemini REST 私有 `vNinternal:*GenerateContent` 路径只处理标题/文本规则，未命中时原样透传；
   - 自定义提示词仅在 invert 主对话路径生效；`custom` 模式不能画成已自动改写所有请求。
6. 外接 BYOK 路由只在配置命中的 `CHAT_PROTO` / `CHAT_RAW` 路径生效；Gemini REST 路径不能画成必然进入 BYOK。
7. `MODEL_UNLOCK` 是响应层目录合并：读取动态模型目录、按 `modelUid` 合并并设置 `disabled=false`；它只代表前端可见性/字段解锁，不保证上游权限或每个模型实际可调用。
8. 代理未健康时，spawn hook 不改写语言服务器参数，清除锚点并回到官方直连（Fail-Safe）。
9. 用虚线标注 `zk-acp-stdio-proxy.js` 为独立的 ACP ndJSON 字节透传脚本；标注“当前 Antigravity 主激活路径不启用 ACP 模式”，不要把它画成主对话注入链路。

禁止出现：`109` 固定模型数、`TAO_TURN_ANCHOR`、`TAO_SUB_ANCHOR`、`100分能力`、`ACP stdio 负责 Antigravity 主对话`、`所有请求必经 BYOK`。

## 提示词二：标题与语言服务器注入细节图

请生成一张 16:9、深色技术信息图，标题为“语言服务器标题请求改写与 Fail-Safe”。使用两个泳道：`Antigravity Gemini REST` 和 `兼容 ACP 透传脚本`；中文字体必须清晰，禁止乱码和文字重叠。

主泳道必须展示：

`request.contents[].parts[].text` 或根级 `contents[].parts[].text` → 检测 `Generate a short conversation title` → 仅替换第一行 → 保留 `Then, in a new line...` 及后续协议 → 输出中文标题提示词。

同时标注两种规则来源：

- Antigravity 私有 Gemini REST 实际写入“首行 4~10 个汉字”；
- 通用 `TITLE_ONLY_ZH_SP` 提示词约束为“8~18 个汉字”；
- 这是提示词约束，不是运行时代码对最终输出长度的硬校验。

语言服务器参数链路标注：健康代理时改写本地代理端点；代理不健康时不改写参数、清除锚点、官方直连。`zk-acp-stdio-proxy.js` 只做 stdin/stdout/stderr 的 ndJSON 字节透传，不负责标题提示词注入。

底部增加“证据边界”说明：标题专项测试验证请求包装路径、首行替换和第二行保留，但不证明模型最终一定返回指定字数。

## 提示词三：能力事实矩阵（替代雷达图）

请生成一张中文深色工程能力矩阵，不使用雷达图、不使用 0~100 分，不写主观“全能”。列为“能力”“代码入口”“生效条件”“证据边界”，行包括：System Prompt 替换、标题提示词替换、LS 参数改写、BYOK 路由、模型目录响应合并、JSONC 注释保留、Fail-Safe 官方直连。每行使用“已实现 / 条件生效 / 仅透传”标签，并显示对应文件名，不要写死模型数量、版本号或端口单值。
